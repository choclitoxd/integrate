# Evaluación de la consola de administración

Evaluación del ADR-0045 del 10 de noviembre de 2026. Versión local basada en `c94bb42` con los cambios del ADR-0045 en el área de trabajo. La API se probó con PostgreSQL 16 en Testcontainers y datos sintéticos. La interfaz se probó con Vitest, axe y el bundle de producción en Chrome headless con una API simulada en localhost.

Los importes de Liquidaciones se derivan de las dispersiones vinculadas al lote. El procesador libera esas dispersiones cuando el proveedor rechaza el lote. La ficha conserva el estado y el motivo de fallo. La referencia del simulador vive en memoria. Tras reiniciar el proceso, una referencia que el simulador no pueda verificar se informa como indisponible.

## Controles automatizados

- Backend. `mvnw.cmd verify` ejecutó 346 pruebas sin fallos y pasó la compuerta de cobertura JaCoCo.
- PWA. Pasaron `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test -- --maxWorkers=2` y `npm run build`. Vitest registró 334 pruebas aprobadas y un fallo esperado.
- Contrato. La comprobación RNF-28 cotejó las rutas de Spring MVC con OpenAPI.

La evaluación en un teléfono físico y los recorridos con sesiones reales quedan pendientes. H-09 conserva también sus criterios independientes de anfitrión, cancelación, perfil y actualización de Mis experiencias tras el pago.
